# AgriConnect Pro

PROMPT MASTER — PLATEFORME DIGITALE PREMIUM DE VENTE DE MACHINES AGRICOLES

INSTRUCTION PRINCIPALE

Conçois une plateforme digitale complète, premium et ultra-professionnelle pour une entreprise spécialisée dans l’importation et la distribution de machines agricoles.

Le produit ne doit surtout pas ressembler à un simple site vitrine, un chatbot ou un dashboard SaaS générique.

Il doit donner l’impression d’être une véritable plateforme commerciale internationale, conçue par une équipe de product designers senior et prête à être présentée à un client professionnel.

La plateforme doit connecter tout le parcours :

Site web → Agent IA → Qualification → CRM → Catalogue → Disponibilité → Demande de devis → Devis → Commande → Paiement → Facturation

Chaque interface doit être cohérente avec les autres.

1. VISION DU PRODUIT

L'entreprise :

importe et revend des machines agricoles ;

possède son siège à Londres ;

développe une activité au Maroc ;

dispose d'équipes à Rabat, Tanger, Fès, Agadir et dans d'autres régions ;

souhaite digitaliser sa relation client et son processus commercial.

La plateforme doit permettre de :

attirer de nouveaux prospects ;

répondre automatiquement aux questions ;

qualifier les prospects grâce à l'IA ;

recommander les machines adaptées ;

transférer les prospects qualifiés à un commercial ;

gérer un catalogue de machines ;

gérer la disponibilité ;

recevoir des demandes ;

créer des devis ;

gérer les commandes ;

gérer les paiements ;

générer les factures ;

centraliser les communications ;

suivre les performances commerciales.
